# Telegram-bot
A Telegram bot built with Python that responds to user messages and commands with customizable responses.
# 🤖 Angheziiobot

A simple Persian Telegram bot built with **Python** using the `python-telegram-bot` library.

The bot can respond to commands and recognize specific messages, making it easy to customize its behavior for different conversations and groups.

## Features

- Responds to `/start`, `/help`, and `/custom` commands
- Recognizes specific Persian messages
- Supports private chats and Telegram groups
- Handles both regular groups and supergroups
- Customizable responses
- Simple and beginner-friendly code structure

## Technologies

- Python
- python-telegram-bot
- Telegram Bot API
- Async/Await
